Privacy Policy

Last updated: 25 November 2026

Focus Frame is a private desktop application used only by its owner to publish videos to the owner's own YouTube channel (Tech Underline). This policy explains what the application does with Google user data.

What data the application accesses

When the owner signs in with Google, the application asks for these permissions:

  • YouTube upload (youtube.upload): to upload videos the owner produced to the owner's own channel.
  • YouTube read-only (youtube.readonly): to read the channel name, video status and public statistics such as views, likes and comments of the owner's own videos.
  • YouTube Analytics read-only (yt-analytics.readonly): to read the owner's own channel analytics, such as watch time, audience retention and viewer countries, in aggregate form.

How the data is used

The data is used only to publish the owner's videos and to show the owner how those videos perform. The application does not read, collect or store personal data about viewers. Analytics are aggregate numbers provided by YouTube.

Storage

Google sign-in tokens are stored only on the owner's own computer, encrypted with the operating system's user-level protection. Statistics reports are stored as local files on the same computer. Nothing is stored on any server operated by the application.

Sharing

Google user data is not sold, shared with, or transferred to any third party, and is not used for advertising. The application's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the application's local data folder removes all stored tokens and reports.

Contact

Questions about this policy can be sent through the Tech Underline YouTube channel.
